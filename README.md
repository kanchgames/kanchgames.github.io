# kanchgames.github.io

The public pages of Kanch Games, published by GitHub Pages: plain HTML and CSS, the Fredoka font hosted here
(`assets/fonts/`, SIL Open Font License), no cookies, no trackers, nothing loaded from another site.

- `/` Kanch Games
- `/casse-glace/` and `/casse-glace/en/` the game
- `/casse-glace/confidentialite/` and `/casse-glace/en/privacy/` the privacy policy
- `/casse-glace/aide/` and `/casse-glace/en/help/` help and contact
- `/app-ads.txt` the sellers' declaration for the game's ads (AdMob): Kanch Games' publisher ID

The icon and the screenshots come from the game's repository (`tools/make_app_icons.py`, `tools/make_store.py`).
